# flo

This repository hosts the informational website for FLO, published with
GitHub Pages.

**Live site:** https://shivampandey-git.github.io/flo/

## What is FLO?

FLO is a proof-of-work cryptocurrency, forked from Bitcoin, best known for
its `floData` field: every transaction can carry up to 1,080 bytes of
arbitrary data, written permanently into the chain.

The FLO Core source code lives in a separate repository:
https://github.com/floreloaded/flo

## About this repo

This repo only contains the static site (`index.html`) and this README. It
does not contain the FLO node software — for that, see the source repo
linked above.

## Updating the site

Edit `index.html` and push to the branch that GitHub Pages is configured to
deploy from. Changes typically go live within a minute or two.
