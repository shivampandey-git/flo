A blockchain built to hold onto things.

FLO is a proof-of-work cryptocurrency, forked from Bitcoin, that adds one deliberate feature: every transaction can carry up to 1,080 bytes of arbitrary data, written permanently into the chain. That's enough room for a signature, a hash, a record, or a small note that outlives whoever wrote it.

the floData field

Payments, plus a place to write.

Ordinary FLO transactions move value the way Bitcoin's do. The difference is a field called floData: an optional slot on every transaction where anyone can attach up to 1,080 bytes of their own data for a small fee. Once it's mined into a block, it sits there permanently, replicated across every full node on the network.

That's enough for a document hash, a timestamped signature, or a pointer into a larger dataset. Projects on top of FLO — the Open Index Protocol among them — use this field to index ownership records, publish content, and build small applications directly on the chain, without needing a separate database.

running a node

FLO Core: download, sync, run.

FLO Core downloads and verifies the full transaction history — currently several gigabytes — and keeps your copy in sync with the network. Depending on your connection, the first sync can take anywhere from a few hours to a day.

  • Unix

    Unpack the release, then run bin/flo-qt for the GUI or bin/flod headless.

  • Windows

    Unpack the release, then run flo-qt.exe.

  • macOS

    Drag FLO-Core into Applications, then launch FLO-Core.

Building from source instead:

git clone https://github.com/floreloaded/flo.git
cd flo
./autogen.sh
./configure
make

Full build notes for each platform live in the doc/ directory of the repository, alongside developer notes and the release process.
